# org

Roster and reporting for the Personal AI Operating System.

- `roster.json` — which seats exist, and which department each one sits in.
  Statuses are a historical snapshot, not a live feed.
- `reporting.json` — who reports to whom, from the owner down through Amanda.
- `roles/` — one file per role.

Keep private memory, contact details, and financial records out of this folder.
The chain of authority is described in the repository [README](../README.md).
