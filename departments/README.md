# departments

Desks for the organization. Each department chief reports to Amanda.
Staff report to their chief. A chief who is not named yet stays an empty seat
until a role request is approved.

Charters in this folder:

- [Finance](finance.md) — Investments, Trading, Playbook / Backtester, Gold
  research, Credit.
- [YouTube](youtube.md) — YouTube Chief, Script Writer, YouTube Analyst,
  YStudio.
- [AI Ops](ai-ops.md) — Rio (architect / developer), Chief Design Engineer,
  OS Tester, Clay Avatar Artist.
- [Ground floor](ground.md) — Mailroom (Gmail head and WhatsApp head), Storage,
  Time Master.
- [Mailroom](mailroom.md) — Gmail and WhatsApp under the Mail Room Chief.
- [Executive](executive.md) — owner and Amanda coordination.

Live account data, message content, and private memory stay out.
