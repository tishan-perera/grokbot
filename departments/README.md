# departments

Desks for the four departments. Each department chief reports to Amanda.
Staff report to their chief. A chief who is not named yet stays an empty seat
until a role request is approved.

- **Finance** — Investments, Trading, Playbook / Backtester, Gold research,
  Credit.
- **YouTube** — YouTube Chief, Script Writer, YouTube Analyst, YStudio.
- **AI Ops** — Rio (architect / developer), Chief Design Engineer, OS Tester,
  Clay Avatar Artist.
- **Ground floor** — Mailroom (Gmail head and WhatsApp head), Storage,
  Time Master.

Department notes that belong in git will be added here later. Live account
data, message content, and private memory stay out.
