# Skills

## Custom skills

No custom (user-created) skills existed in the organization's skill folder on Nov 18, 2026. Repeatable procedures live in the routines, decision records and seat instructions instead.

## Platform skills the org relies on

The original platform (Grok Bot) ships built-in playbooks. A rebuild on another platform needs equivalents for:

- Routines: creating and changing scheduled or event-driven work.
- Scheduling: calendar reads and availability.
- Code changes and source control: repository work through cloud agents and pull requests.
- Pages (canvas): writing and editing dashboard Pages in React/TSX.
- Send on behalf: drafting messages as Tishan, sent only after approval.
- Vault and sign-in: handling credentials without exposing them to agents.
- Voice: optional voice memos.
