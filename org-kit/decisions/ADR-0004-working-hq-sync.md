# ADR-0004: Working HQ sync protocol

- Status: Accepted (interim) — Amanda overnight project control; Tishan's own-words ask Nov 1, 2026 ~10:17 PM ET. Anything beyond these rules is Proposed-pending-Tishan.
- Date: 2026-11-01

## Context

Tishan asked for the Virtual HQ to show what is working and updated right now. He will teach each agent soon and wants the OS kept in sync as agents learn and as he hires or fires.

## Decision

1. The Floor Page is the source of truth. The Virtual Office is a mirror.
2. Amanda owns hire / fire / teach status writes (after Tishan's own-words OK for any structure change).
3. On every hire, fire, or teach milestone, Amanda pings Rio → Rio edits the Floor the same day, then mirrors the Virtual Office.
4. Statuses are Working / Waiting on Tishan / Closed, with an as-of time. No invented heartbeats.
5. No org restructure without Tishan.
6. No Storage Drive / GROKBOT METHOD work until Tishan greenlights it.
7. The four paused Wave 1 routines stay paused until Tishan confirms. The digest stays live.

## In plain words
Amanda tells Rio when someone is hired, let go, or taught something new. Rio updates the main Floor page that day, then the picture office. Nothing is shown as "live" unless someone actually reported it.
